# 🚀 MurasAI — AI-powered Learning Platform

MurasAI is an AI-driven LMS prototype designed to help students prepare for exams using intelligent tools such as an AI tutor, test generator, and personalized study planning.

This project was built as a hackathon MVP inspired by AVN LMS, enhanced with artificial intelligence capabilities.

---

## 🧠 Features

#2962FF

### 🤖 AI Study Assistant
- Chat-based AI tutor
- Explains topics clearly
- Helps students prepare for exams

### 📝 Test Generator
- Generate tests by topic and difficulty
- Multiple-choice questions
- Instant results

### 📅 Study Planner
- AI-generated study roadmap
- Personalized preparation plan
